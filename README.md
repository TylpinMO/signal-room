# Signal Room

Signal Room is an interactive product analytics dashboard focused on the questions a growth team checks every morning: revenue movement, acquisition quality, activation drop-off, and retention health.

[Open the live dashboard](https://tylpinmo.github.io/signal-room/)

## Highlights

- Range-aware revenue chart for 7, 30, and 90-day views
- Filterable acquisition table with realistic channel data
- Campaign-aware activation funnel and actionable insight
- Cohort retention heatmap
- Responsive desktop, compact-sidebar, and mobile layouts
- Keyboard focus states and reduced-motion support

## Stack

React 19, TypeScript, Next-compatible routing through Vinext, and CSS.
