# Signal Room

Интерактивная панель продуктовой аналитики: выручка, источники трафика, активация и удержание собраны в одном интерфейсе.

## Возможности

- переключение периода между 7, 30 и 90 днями;
- фильтрация каналов привлечения;
- воронка активации с выбором кампании;
- когортная карта удержания;
- адаптивные состояния для desktop, компактного sidebar и телефона;
- клавиатурная навигация и поддержка `prefers-reduced-motion`.

Данные демонстрационные: проект показывает работу с интерфейсом аналитического продукта, а не подключение к реальному бизнесу.

## Стек

React 19, TypeScript, Vite, CSS, GitHub Actions, Vercel.

## Локальный запуск

```bash
npm ci
npm run dev
```

Полная проверка:

```bash
npm test
```
